## Correcciones obligatorias frente a los mockups

- Serie Preventivo #24284D; Correctivo #C45D23. CTA #EA7515, texto navy. No copiar naranja brillante ni gradientes de las imágenes.
- El acumulado financiero correcto del ejemplo es **45,600**, Preventivo **18,600** y Correctivo **27,000**. Categorías corregidas: Refacciones **26,000**, Mano de obra **16,000**, Otros **3,600**. Las imágenes conservan cifras erróneas y segmentos de barras no proporcionales; reconstruir desde los datos de la SPEC.
- ACTIVA/INACTIVA es estado administrativo, no estado operativo ni aptitud.
- Marca/modelo sigue siendo un campo combinado; VIN existente se conserva.
- Editar/Completar solo con permiso actual; el botón Actualizar kilometraje está fuera de A hasta definir un flujo real.
- Las imágenes omiten Salud; el sistema sí tiene cálculo/desglose. Resolver D-01 antes de cambiar su presentación.
- Mantener nombres completos de las cuatro secciones, incluido Mantenimiento en móvil; no copiar Mantto. como única etiqueta.
- Filtros, tipografía, categorías y botones se ajustan al sistema existente; las imágenes no autorizan nuevos componentes, permisos o tokens.
- Periodo/moneda de costos y números/IDs de órdenes son ilustrativos. No corresponden a gastos reales confirmados de FOTON.

La meta 8.5 requiere la auditoría independiente de la UI implementada descrita en la UX spec; estas imágenes no acreditan cumplimiento.
