## Objective

Each operator control states the record it writes, and a regreso commits only a unit the operator selected.

## Context

Kernel `ops_estado` and patio `SALIDA` stay independent. `/flota` could commit `enRuta[0]`. Visit close confirmed edit-lock only. **Marcar recibida** does not post stock. `/inicio` treated a failed source as zero.

## Scope

- Regreso sheet: picker of the filtered `EN_RUTA` rows; submit disabled until one is chosen.
- Sheet shows viaje salida time and patio open-salida from `GET /flota/tablero` (separate read).
- **Sin regreso** sort oldest `salidaAt` first; column **Desde la salida**.
- Clock help names the viaje `En ruta` clock, not patio salida.
- Visit close dialog lists stock lines, compra externa, and Andon resolve.
- Draft persist refuses `DESDE_STOCK` over the client snapshot.
- Ajuste shows `hay → quedarán` and blocks a negative result.
- **Cerrar comprobante** copy: no stock change.
- `/inicio` names a failed source and limits the empty sentence to the three sources it loads.
- Nav and Andon title: **Mantenimiento vencido**. Piezas heading **En esta visita**.

## Out of Scope

- UI for `POST /logistica/salidas`.
- Deriving `ops_estado` from patio.
- New `/inicio` sources (salud, sin regreso).
- `api/src`, schemas, notify.
- Renaming patio tablero title `En ruta · {sitio}` (fleet-tablero-viaje-v0).

## UI scope supersession

The `/logistica` movements dashboard and its departure/return entry points are now governed by [EWO-008](EWO-008.md) and [SPEC-LOGISTICA-DASHBOARD-001](../specs/logistica-dashboard-v0.md). EWO-006 retains its state-fidelity/API constraints; do not use its historical “UI for `POST /logistica/salidas`” exclusion to block the separately approved EWO-008 flow.

## Domain Rules

- Regreso writes kernel viaje only.
- Patio salida abierta is displayed, not updated, by the regreso sheet.
- `cerrar` side effects stay server-side; the dialog describes them.
- Cerrar comprobante does not change on-hand.

## Dependencies

- None on EWO-001–005 except shared alert help copy.

## Acceptance Criteria

### AC-01
Given two units `EN_RUTA` and a **Sin regreso** filter on one of them, when the operator opens **Registrar regreso**, then no unit is preselected from the unfiltered list and submit stays disabled until that operator picks a row.

### AC-02
Given a selected unit with an open patio `SALIDA`, when the sheet is open, then it says patio salida abierta and that regreso does not register patio entrada.

### AC-03
Given piezas `DESDE_STOCK` over stock, when the operator uses the stepper or **Guardar y salir**, then the draft is not patched.

### AC-04
Given the confirm step with no faltantes, when the operator chooses **Cerrar visita**, then a dialog lists each line’s stock effect before the POST.

### AC-05
Given a failed Andon load and a successful stock load, when `/inicio` renders, then it says mantenimiento vencido failed and still lists stock exceptions.

## Testing Requirements

- UI: `cd web && npx tsc --noEmit` and `npm run lint` on touched files. Click-through of `/flota`, visit confirm, `/inicio`, ajuste, por recibir.
- API: no `api/src` change.

## Constraints

### Architecture

No cross-schema join. Tablero is a second HTTP read.

### Compatibility

Patio ficha route for `DISPONIBLE` rows stays.

### Security

### Performance

One extra `GET /flota/tablero` on desk load.

### UX

One orange CTA on the desk. Dialog uses existing `Dialog`.
