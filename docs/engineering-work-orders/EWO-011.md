## Objective

Hacer autoritativo en PostgreSQL el máximo de un borrador por unidad y crear una visita con chofer, km y tipo de forma atómica, con resultado estable ante reintentos y carreras.

## Scope

- DTO y contrato de creación de visita.
- Transacción, validaciones existentes y resultado `CREATED`/`EXISTING_DRAFT`.
- Auditoría no destructiva e índice único parcial idempotente.
- Pruebas unitarias/servicio y e2e, incluida concurrencia.
- Caracterización de update, delete, close y outbox.

## Out of Scope

- UI, resolución automática de duplicados, política global de migraciones, endpoint analítico, enum nuevo o cambios a `VisitaCerrada`.

## Domain Rules

- `0..1 BORRADOR` por unidad; unidad `ACTIVA`; actor `SUPERVISOR`; chofer `ACTIVO`; km persistible; tipo existente.
- La carrera devuelve el borrador ganador; nunca crea una segunda fila.
- Duplicados previos se reportan y bloquean sin mutación.

## Dependencies

- SPEC y ADR-015 aprobados.
- Base PostgreSQL descartable confirmada para e2e.

## Constraints

### Architecture

Public/Mantenimiento only; no cross-schema JOIN/FK; ADR-015 exact outcomes; no general migration framework.

### Compatibility

`PATCH`, delete and close remain available. Update all in-repo create callers in the dependent UI EWO, not here.

### Security

Role validation remains server-side; no client-trusted unit/driver state.

### Performance

Partial unique index on `unidad_id`; duplicate audit is bounded deployment work, not a request-path scan.
