# EWO-039 — Compatibilidad por tipo o unidad específica

## Status

Closed for local implementation and verification. Independent Visual QA: OK. Approved 2026-10-13 by the request to select tipos de unidad or unidades específicas and the explicit answer “Permitir combinar tipos y unidades”. Extension to PR94; no production rollout.

## Scope and rules

Inventory owns compatibility of a catalog refacción with selected types and/or individually selected units. This is catalog compatibility, not stock reserved or installed on a vehicle. Matching uses the union: selected type OR selected unit. Units resolve through the Kernel service; no cross-schema FK/JOIN. Existing type matches remain unchanged; new unit selections default empty. No change to costs, closure, stock or roles.

Canonical ACs:
- UNIT-01: type-only, unit-only or combined selection persists on create/read/update; duplicates removed.
- UNIT-02: unknown/malformed references fail without a partial item/compatibility update.
- UNIT-03: filtering by unit derives its current type and returns type matches plus explicit unit matches once; another unit of the same type does not inherit a specific-only match.
- UNIT-04: type-only legacy requests keep their behavior; omitted unit selections preserve existing data; explicit empty selections clear only unit compatibility.
- UNIT-05: Spanish shared alta lets users search by number/plates/model, retains selections across searches, labels selected units and blocks empty compatibility capture.
- UNIT-06: native390/1024/1440 proof, separate ux-auditor and relevant API/web checks.
