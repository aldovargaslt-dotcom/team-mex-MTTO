## Scope

- Editor responsive y sus estados de carga, vacío, error, validación y confirmación.
- Estado local de búsqueda, filtros, selección, borradores, lotes y pendientes; referencia mensual compartida.
- Orquestación de PATCH secuenciales y reconciliación de resultados; integración con stock e inbox existentes.
- Pruebas de lógica y regresiones de contratos usados, click-through y proof UI; auditoría visual independiente posterior.

## Out of Scope

- Despliegue o migraciones productivas; publicación limitada al código/evidencia autorizados.
- Rediseñar Existencias o Configuración → Alertas; editar crítico directamente; recomendaciones de mínimos, consumo neto o reposición automática.
- Guardado masivo atómico, versionado/locks nuevos, nuevos endpoints, esquemas, migraciones o permisos.
- Lotes de trazabilidad de almacén, multi-almacén, compras, costeo, reservas y kardex. «Lote» aquí es edición de una selección de productos.
- Cambios a Flota, Mantenimiento, Andon, ownership, motores de severidad, auditoría del editor de catálogo o dual-stack notify.
- Frameworks de prueba UI, Playwright, tokens, fuentes, shell o dependencias de diseño nuevas.

## Constraints

### Architecture

Reutilizar GET stock/movimientos y PATCH ítem; monolito modular, sin JOIN/FK cruzados ni cambios a puertos. Sin API runtime previsto. Si se necesita contrato o regla nuevos, detener y revisar SPEC/ADR/EWO.

### Compatibility

Preservar contratos, inactivos, null/cero, permisos, eventos y concurrencia actuales. Mantener consultas 7/30/90 y funcionalidades de consulta/entrada/ficha fuera del modal. Ningún guardado global atómico ni garantía exactly-once.

### Security

Auth/proxy existentes; sin permisos nuevos. Evidencia sin credenciales ni datos productivos. Logística no gana acceso. Si cambia rol/sesión, invalidar estado/solicitudes del editor para no mezclar actores.

### Performance

Filtrado local sobre ~100 filas; una lectura mensual compartida completa por apertura/reintento. No N+1, truncado silencioso ni virtualización obligatoria. Inspeccionar número de consultas y usabilidad del catálogo; separar el volumen histórico del tamaño del catálogo.

### UX

UX canónica y gate anterior; español operacional, errores cercanos al CTA y acceso a filas ocultas. Usar Dialog/portal, Input, Button, Field, FormAlert, ListFilter y tabla compartida. No instalar skills/frameworks ni rediseñar shell.
