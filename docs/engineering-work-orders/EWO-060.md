# EWO-060 — Chequeo diario único, sin clasificación Daily/Stock

Completed locally / verified, sin deploy. Usuario2026-10-18: inactivar Daily/Stock, solo diario; diariamente
abrir una orden de chequeo. Autoriza este incremento, no deploy.

## Decisión y alcance

Política efectiva DAILY universal, independiente de configuración histórica.
Eliminar controles Daily/Stock/clasificación y programación variable de UI;
configuración histórica se conserva pero no gobierna próximos checks.
Generación automática por jornada CDMX, unidad ACTIVA/EN_PATIO sin inconsistencia;
no duplicar CHECK activo ni más de una generación automática por unidad/jornada.
Viaje no cambia al vencer ni genera retiro/reparación. Retorno permite generación
en siguiente tick si corresponde. CHECK nace PENDING, no abre mantenimiento.
Manual/recheck existente se mantiene. Deadline nuevo fin de jornada CDMX; firmas
históricas no se reescriben: lectura operativa exige también jornada diaria actual.
ADR029 acota sustitución de ADR028. Config legacy write deshabilitado, read histórico.

Scheduler con tick periódico, inicio/parada lifecycle y retry; mismo comando
serializado entre instancias. CHECK_DAILY_ENABLED=false permite apagado explícito;
NODE_ENV=test no autoejecuta lifecycle. Sin cron externo, migración ni permisos nuevos.
