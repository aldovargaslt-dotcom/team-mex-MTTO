## Objective

Group the shared sidebar catalog by domain without changing routes, roles or permissions.

## Scope

- `group` field in `ApplicationNavigation.tsx`; items ordered by group; group headings (desktop, collapsed separator, mobile menu).
- Groups: Operación (Inicio, Órdenes, Movimientos, Mi trabajo), Flota (Unidades, Choferes, Mantenimiento vencido), Inventario y análisis, Administración (Configuración, Usuarios).
- Standard updated in `APPLICATION_NAVIGATION.md`.

## Out of Scope

Routes, permissions, labels, icons, inventory/analysis sub-navigation, bottom navigation, palette.

## Acceptance Criteria

Source: this EWO.
- AC-1: Each role sees the same destinations as before (no item added, removed or re-permissioned).
- AC-2: Headings render only when the role sees more than one group.
- AC-3: Collapsed sidebar shows separators, not text; mobile menu shows headings.
- AC-4: Bottom navigation order is unchanged.
- AC-5: `npm run lint` and `npm run build` pass.

## Testing Requirements

`cd web && npm run lint && npm run build`; `proof-ui` for Admin, Supervisor, Logística, Mecánico, desktop open/collapsed and mobile (standard's review rule).

## Constraints

Follow APPLICATION_NAVIGATION: no second sidebar, no feature-level `.app-sidebar` rules.

## Escalation Conditions

Choferes placement and the group names are product decisions; the Owner may change them.
