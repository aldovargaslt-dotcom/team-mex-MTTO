## Operational limits / handoff

Exact internal decimal scale6, paid scale2, per-item quantity scale0–6; UI uses display formatting only. The pilot serializes inventory financial posting with one database advisory mutex; this intentionally favors correctness and cross-OT repricing over throughput. Persisted source allocations are analytical value provenance, not physical lots. Secure evidence reuses the existing storage port with image magic/size limits and permissions. Corrected financial records never edit km/work/signatures or reemit completed-maintenance events.

Rollout requires reviewed backup and the explicit cost migration runner; no automatic production down/truncation. All verification findings were resolved; final local implementation is ready for review. Native UI proof also used a separate disposable `ewo038_ui_test` database for the final receipt deeplink shots while the main regression suite ran; same preprovisioned PostgreSQL, synthetic data only.
