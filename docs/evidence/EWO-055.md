## Causa y prevención

Había una excepción heredada para Admin porque AppShell solo montaba barra inferior para Supervisor; InventarioNav compensaba con selector superior. Se conservó erróneamente en054 pese al estándar pedido. La corrección comparte el patrón existente y enmienda contrato/UX/SPEC para que otros agentes no restauren la excepción. Los destinos adicionales de Admin siguen disponibles en menú global. No se reescribe evidencia054 como si ya hubiera probado este comportamiento.
