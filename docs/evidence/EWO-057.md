sobre el incremento readiness de EWO-056; no modifica API, permisos ni reglas.

## Resultado

- Shell compartido: sidebar224 contraíble a72 en escritorio; navegación completa
  por rol, ubicación activa y controles de sesión. Header contextual blanco;
  Sheet izquierdo móvil, cierre por Escape y foco al disparador. CHECK conserva
  superficie concentrada sin nav inferior superpuesta.
- Primario navy/blanco desde tokens compartidos, también en Dialog/Sheet portales.
  Roboto, semántica de estados y marca conservadas.
- Unidades compacta filtros secundarios progresivos; ficha ajusta escala y ritmo,
  sin nueva sidebar local ni KPIs. Uso actual accesible junto ABC a1024 cuando se
  oculta su columna. Todos los filtros y acciones funcionales permanecen.

Fixtures visuales **interceptados en window.fetch mediante CDP**, temporales en
`/tmp/ewo048`; no cambian código de producto, sesiones reales ni base de datos.
El primer harness tenía un payload de Inicio incompleto y falló; se corrigió el
fixture. Una nueva sesión CDP debía reinstalar el fixture: el primer intento de
confirmación no generó captura y se corrigió. Recorridos finales sin excepciones.
No se acredita backend, persistencia o inspección física con estos PNG.
Regresión API no repetida: este pase es visual y no modifica API.

recorridos completos en navegador en este pase.
