# EWO-061 — Cierre del estándar de sidebar

2026-10-18. Usuario aprueba sidebar nueva como estándar compartido para evitar
variantes respecto a main y retrabajos.
[EWO](../engineering-work-orders/EWO-061.md),
[contrato canónico](../design/APPLICATION_NAVIGATION.md).

## Causa y corrección

EWO058 había acotado selección navy/blanco a Unidades mediante readiness.css;
las demás rutas conservaban selección gris. Además existía un catálogo duplicado
entre menú principal y accesos inferiores. En esta rama esos estilos todavía no
estaban integrados en main. El screenshot del usuario corresponde a otra revisión;
no se usa como una segunda definición del shell aprobado.

- Estado activo navy/blanco ahora vive exclusivamente en workspace.css, igual
  para Inicio/Unidades/Inventario/Configuración y menú Sheet.
- ApplicationNavigation centraliza catálogo por rol, etiquetas/iconos, selección
  por límites de ruta y renderer desktop/móvil. Accesos inferiores se derivan
  del catálogo sin duplicar etiquetas/iconos. Rutas/permisos conservados.
- Se retiraron reglas sidebar de readiness.css y estados legados del Sheet de
  globals.css; CSS de features no define navegación principal.
- AppShell conserva marca, sesión, topbar, expansión y excepciones `/` y CHECK.
  Enlaces en estado contraído tienen nombre accesible/title, incluido Elegir rol.
- Estándar enlazado desde DESIGN, índice diseño, design system, ADR003, AGENTS e
  ICM. Futuras pantallas usan shell existente; revisión debe cubrir varias rutas.
