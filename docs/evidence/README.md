# Verification evidence

Where an agent files **closure evidence** for an Engineering Work Order (`EWO-xxx`).

- Template: [EVIDENCE-TEMPLATE.md](EVIDENCE-TEMPLATE.md)
- UI click-through PNGs already live in [`docs/screenshots/`](../screenshots/) (skill `proof-ui`). Point to them; do not duplicate binaries here unless needed.
- API: commands in skill `verify-api` / `script/verify.sh`. Paste results, do not invent pass/fail.

This folder is empty of product evidence until a real EWO is executed. Do not add speculative files.
