# Discovery Workspace

Temporary notes for understanding a problem **before** choosing a solution.

Typical contents:

- observations;
- process notes;
- stakeholder needs;
- evidence;
- problem statements;
- assumptions;
- unresolved questions.

Discovery artifacts are **not** approved requirements. Promote durable knowledge into `context/`, `domain/`, SPECs, or ADRs.
