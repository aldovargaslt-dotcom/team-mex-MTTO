# Shaping Workspace

Compare solution options **before** commitment.

Typical contents:

- options;
- trade-off analysis;
- proposal;
- constraints;
- decision record before formal SPEC/ADR/EWO.

Keep `PROPOSAL` and `DECISION` distinct. Once accepted, move durable behavior into SPEC / domain card / `docs/adr/`.

Do not create speculative ADRs or EWOs from an unaccepted shaping note.
